## 8. ROLLBACK PLAN

### Trigger conditions for IMMEDIATE rollback (one or more)

- [ ] **Auth broken**: users can't login or sign up (Key Flow step 4 login/signup tests red × 2 attempts with different browsers)
- [ ] **Payment / checkout broken**: /pricing → stripe checkout fails
- [ ] **Diagnostic flows broken**: /assessment/*/take returns 5xx or crashes
- [ ] **Error rate > 5%** on any public page (Sentry dashboard, past 10 minutes)
- [ ] **Complete site outage > 2 minutes**: homepage returns 5xx / SSL error / blank

### Rollback steps

1. Go to **Vercel Dashboard → https://vercel.com/lyc-partners/lyc-website/deployments**
2. Find the deployment labelled **Production BEFORE promote** (the one running v1.5) — sort by Created, the production deploy before the one you promoted.
3. Click the `•••` menu → **Promote to Production**
4. Wait ~2 min for edge re-deploy; site returns to v1.5.
5. Verify homepage returns, auth works, diagnostics load.
6. Notify Kevin + #ops channel: "ROLLBACK v1.5 @ timestamp due to <reason>".
7. Debug on staging re-env, write V5.3 hotfix branch with the corrected file(s), do NOT re-promote until staging is green again for the same key flow that failed.

### Less-than-immediate issues (no rollback, just hotfix)
If only aesthetic (e.g. alignment, spacing, copy typo, single non-critical link wrong):
- Open V5.3 hotfix PR → fix → staging green → ship via normal promote.
- No rollback needed.
